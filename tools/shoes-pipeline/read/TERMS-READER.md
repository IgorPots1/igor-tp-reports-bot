# Чтение условий использования: инструкция

Ты читаешь текст условий использования сайта (terms of use, пользовательское
соглашение, оферта) и решаешь одно: можно ли нашему конвейеру брать с этого сайта
страницы.

Что делает конвейер, чтобы ты судил о нём, а не вообще:
- скачивает страницы сайта программой (робот, скрипт) с паузами;
- хранит их копию на диске;
- модель читает обзор и выписывает короткие вердикты и цитаты; из них
  собирается каталог подбора кроссовок — это производная работа;
- каталог работает на коммерческом сайте (лид-магнит тренера).

## Решение

`forbids` — если условия прямо запрещают хоть что-то одно:
- автоматический доступ: robots, spiders, scrapers, crawlers, bots, scripts,
  data mining, extraction tools, «автоматизированные средства», парсинг;
- хранение / копирование / воспроизведение контента (store, copy, reproduce,
  download — кроме разового просмотра);
- производные работы, компиляции, переработку (derivative works, compilations,
  modify, adapt, переработка);
- использование контента для ИИ / машинного обучения;
- любое использование кроме личного некоммерческого (personal, non-commercial
  use only; только для личного использования).

`permits` — только если условия прочитаны целиком и НИ ОДНОГО из пунктов выше
нет, либо есть явное разрешение (например, лицензия Creative Commons BY/BY-SA,
разрешающая переработку). Отсутствие запрета на одну вещь не значит разрешение,
если есть запрет на другую.

`unread` — если текст не условия использования сайта (это оферта продажи
товара, политика конфиденциальности, пустая страница, текст обрезан или
рисуется скриптом), и судить по нему нельзя. Не угадывай.

Сомневаешься между `permits` и чем-то ещё — выбирай не `permits`.

## Цитата

Для `forbids` — дословный пункт с запретом. Для `permits` — дословный пункт,
который определяет допустимое использование (или лицензия). Для `unread` —
`null`. Цитата копируется из файла символ в символ, 30–400 знаков, одним куском
(без склейки мест). Код проверит её точной подстрокой.

## Ответ

JSON-массив, по объекту на источник:

```json
[
  { "id": "example", "reading": "forbids", "quote": "...", "why": "кратко по-русски" }
]
```
