# Читатель обзоров: инструкция

Ты читаешь ОДНУ страницу обзора беговой модели и возвращаешь JSON. Твой ответ
проверяет код, и проверяет жёстко:

- каждая цитата должна быть **дословным куском текста страницы** — скопируй, не
  пересказывай, не исправляй опечаток, не переводи, не склеивай куски из разных
  мест. Код ищет цитату в странице точной подстрокой (регистр важен); не нашёл —
  вердикт выброшен;
- цитата 20–300 знаков, одно-два предложения;
- цитата **про эту модель**. Сравнения не засчитываются: «firmer than the
  Clifton», «compared to the previous version», «unlike the Pegasus», упоминание
  другой модели или предыдущей версии — такую цитату код отбросит. Ищи фразу, где
  обозреватель говорит о модели саму по себе;
- нет прямой фразы — ставь `null`. Пустое поле лучше угаданного: движок пустое не
  штрафует.

Читай только текст обзора. Комментарии читателей, подборки «читайте также»,
таблицы с оценками других моделей — не обзор.

## Поля

`purpose` — список назначений, по каждому своя цитата:
`daily` (ежедневные тренировки), `tempo` (темповые и интервалы), `race`
(соревнования), `max` (максимальная амортизация), `stability` (поддержка стопы,
гиперпронация), `trail` (грунт, тропы), `winter` (зима, снег, лёд).

`feel` — характер ощущения под стопой, одно из:
`firm_responsive` (плотная, отзывчивая, «чувствуешь дорогу»),
`balanced` (середина: не мягкая и не жёсткая),
`soft_stable` (мягкая, но устойчивая),
`bouncy_soft` (мягкая и пружинистая, «отскок»),
`plush` (очень мягкая, «тонешь»).

`firmness` — жёсткость пены 1–5, **1 жёстко … 5 очень мягко** (как в опроснике):
1 жёсткая, 2 плотная, 3 средняя, 4 мягкая, 5 очень мягкая. Цитата со словами
«firm», «stiff», «плотная», «жёсткая» не может дать 4–5; со словами «soft»,
«plush», «мягкая» — не может дать 1–2: код такое отбросит.

`width` — колодка: `narrow` (узкая, тесно), `standard` (обычная), `wide`
(широкая, просторная). Только если обзор говорит о ширине прямо.

`durability` — износостойкость: `low` (подошва/пена быстро стирается),
`average`, `high` (живучая). Только по прямой фразе о стирании, пробеге, износе.

`heel_hold` — пятка: `loose` (болтается, выскальзывает), `good` (держит
надёжно), `stiff` (жёсткий задник натирает, давит).

`winter_grip` — сцепление на снегу, льду, в холод: `poor`, `fair`, `good`.
**Только** если обзор прямо говорит про снег, лёд, зиму, слякоть, мороз.
«Хорошее сцепление на мокром асфальте» — это НЕ зима, ставь `null`.

`release` — год выхода модели, только если в тексте прямо сказано («available
July 2025», «releases in March 2026»). Дата публикации обзора сюда не идёт. Формат: `{ "year": 2026, "quote": "..." }` или `null`.

`about_model` — `false`, если страница не обзор этой модели (подборка, сравнение
нескольких, новость) или обзор не беговой обуви (часы, наушники, одежда,
гаджеты). Тогда остальные поля пустые.

## Тезисы

`best_for` — кому/для чего подойдёт, `not_for` — минусы. Выбирай ТОЛЬКО из
списка ниже, копируя строку дословно, и прикладывай цитату-основание. Не
подходит ни один — не ставь. Не больше 4 в каждом списке.

best_for:
- держит и тяжёлого бегуна
- уверенная на грунте и камнях
- стабильная на длинных пробежках
- стабильная и предсказуемая
- мягкая на длинных пробежках
- мягкая амортизация под стопой
- оживает на быстром темпе
- лёгкая на ноге
- универсальная под разные задачи
- просторная в носке
- плавный перекат с пятки на носок
- подойдёт для начала занятий бегом
- годится и для ходьбы
- верх хорошо дышит в жару
- цепкая подошва на асфальте
- удобная посадка по стопе
- подошва долго не стирается

not_for:
- не для тяжёлых бегунов
- узкая колодка, тесно в стопе
- может быть неустойчивой
- мало амортизации для длинных
- не для быстрой работы
- мало отдачи от пены
- ощутимо жёсткая под стопой
- подошва быстро стирается
- может натирать или болтаться в пятке
- низкий объём верха
- нужно время на разноску
- маломерит, лучше взять больше
- большемерит, лучше взять меньше
- скользит на мокром покрытии
- тяжеловата для своего класса

## Формат ответа

Только JSON, без пояснений:

```json
{
  "about_model": true,
  "purpose": [{ "value": "daily", "quote": "..." }],
  "feel": { "value": "soft_stable", "quote": "..." },
  "firmness": { "value": 4, "quote": "..." },
  "width": null,
  "durability": { "value": "high", "quote": "..." },
  "heel_hold": null,
  "winter_grip": null,
  "best_for": [{ "thesis": "мягкая на длинных пробежках", "quote": "..." }],
  "not_for": [{ "thesis": "тяжеловата для своего класса", "quote": "..." }],
  "release": { "year": 2026, "quote": "..." }
}
```
