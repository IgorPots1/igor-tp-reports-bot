# Конвейер сбора базы кроссовок

Этап 1 к подборщику (`/tools/shoes`).

## Что здесь сейчас и почему так мало

13.10.2026 наряд переписан целиком, и причина внешняя: **RunRepeat отказал в
использовании своих данных**. На их лабораторных замерах держалась вся прежняя
схема — твёрдость межподошвы, жёсткость задника, износостойкость, толщина
подошвы. Больше нигде в мире эти величины не публикуются, поэтому схема «с
цифрами» не чинится добором источников, а отменяется.

Вместе с их замерами снят и измерительный слой целиком: новый наряд не берёт
измеренные значения **ни у кого**. База строится из свода обзоров —
качественных вердиктов (для чего модель, кому подойдёт, кому нет), каждый не
меньше чем на двух прочитанных обзорах со ссылками.

Поэтому из конвейера удалены сборщики и разборщики страниц, сборка каталога по
старой схеме и всё, что выводилось из чужих замеров. Осталось то, что от схемы
не зависит и нужно в любом виде сбора:

| Файл | Что делает |
|---|---|
| `lib/sources.ts` | реестр источников — он же гейт: статус ≠ `allowed` означает, что страницы не скачиваются |
| `lib/robots.ts` | разбор robots.txt: группы, Allow/Disallow, победа самого длинного правила, `*` и `$` |
| `lib/fetch.ts` | загрузчик: спрашивает гейт, уважает robots и Crawl-delay, держит паузу на хост, кэширует на диск |
| `lib/reconcile.ts` | сверка источников: нет источника — не берём, один источник — мало, расхождение не усредняется |
| `lib/tiers.ts` | пороги уровней по распределению собранных цен (терцили), а не на глаз |
| `lib/match.ts` | сопоставление одной модели в разных источниках, строго и без нечёткого сходства |
| `audit-sources.ts` | гейт условий использования: читается ДО сбора |
| `coverage-report.ts` | где база тонкая — прогоном настоящего подбора, а не пересказом фильтров |
| `check-pipeline-rules.ts` | правила сверки и порогов на заданных входах, без сети |

## Запуск

```
# Гейт: условия использования источников. Без него загрузчик не работает.
npx tsx tools/shoes-pipeline/audit-sources.ts

# Правила сверки и порогов — без сети.
npm run check:shoes-pipeline-rules
npm run typecheck:shoes-pipeline

# Где база тонкая (на любом каталоге по схеме приложения).
npx tsx tools/shoes-pipeline/coverage-report.ts data/shoes/catalog.demo.json
```

## Правила, которые конвейер держит

- **Источник, запрещающий сбор, не включается.** Гейт спрашивается перед каждым
  запросом; отчёт аудита протухает через 30 дней и требует перепроверки, потому
  что условия меняются, а унаследованное «можно» никто не проверял.
- **Поле без источника в базу не попадает.** В новой схеме это ужесточается:
  вердикт без ДВУХ прочитанных обзоров со ссылками не попадает тоже.
- **Расхождение не усредняется.** Один обзор называет модель мягкой, второй
  плотной — поле уходит человеку. Среднее дало бы значение, которого не говорил
  ни один источник.
- **Кэш страниц** (`tools/shoes-pipeline/.cache/`, в git не идёт) — это ещё и
  доказательство: вывод прослеживается до сохранённой страницы.

## Чего здесь больше нет и не будет

RunRepeat — ни сборщика, ни разборщика, ни записи в реестре источников. Запись
убрана целиком, а не переведена в статус «запрещён»: статус можно переключить
обратно одной строкой, отсутствие записи — нельзя.
