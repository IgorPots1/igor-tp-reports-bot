# Задачи 2+3 — клубный лидерборд (ветка feature/club-tops-best-times)

## Решение (утверждено Игорем)
Клубный топ = **лучшее время на дистанцию у каждого, включая Strava** (measured best-effort).
Личная карточка «Гонки / Лучшие отрезки» — БЕЗ изменений (разделение по смыслу там остаётся).
Меняется только клубный лидерборд.

## Как считается (getClubRecords.clubTops)
Кандидат на дистанцию у ученика = БЫСТРЕЙШЕЕ из доступного:
- coach_confirmed (verified) — гонка; hidden/preliminary → ученик исключён на этой дистанции;
- official_protocol — гонка;
- race_events (raceVerified из снапшота) — реконструированная гонка;
- **strava_best_effort — лучший отрезок тренировки** (раньше в топы НЕ шёл).
Берём минимальное время, помечаем источником. Идём по ВСЕМ видимым ученикам (не только со снапшотом).

## UI
- Каждая строка несёт `source`; строки `strava_best_effort` помечены бейджем **«Strava»** (задача 3:
  «в одном списке гонки с протоколом и отрезки — разница должна читаться»).
- Полный список: **10 по умолчанию + кнопка «Показать всех (N)»** (задача 2). Свёрнутый блок.
- Шапка «только гонки» убрана; примечание: «Лучшее время… Пометка Strava — отрезок из тренировки».
- Убрано старое примечание «5к в топ не идёт» — теперь 5к-топ есть.
