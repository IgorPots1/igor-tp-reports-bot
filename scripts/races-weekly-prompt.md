ВХОДНЫЕ ФАЙЛЫ (уже лежат в рабочей папке)
- `manual.json`: активные ручные старты с датой от сегодня.
- `sources.json`: источники, у которых на этой неделе подошёл срок проверки. Уровень в поле `tier`:
  B (организатор или серия с несколькими стартами, каждую неделю), C (сайт одного старта, раз в месяц
  и каждую неделю за 3 месяца до прошлогодней даты). Уровень A (агрегаторы) собирает робот, их тут нет.
- `suggestions.json`: заявки посетителей /races (форма «Добавить старт»), статус new.
- `cities.json`: точки обхода этой недели (города и трейловые места).
- Поиск во ВКонтакте: {{VK}}. Если «есть», `vk-candidates.json` — посты открытых сообществ по ВСЕМ точкам
  (8 слов × город × год), уже отобранные шлюзом: с датой и словом про бег, без рекламы туров и итогов.
  Проверь каждый пост по правилам insert; для стены группы организатора есть `npx tsx {{REPO}}/scripts/races-manual.ts vk wall.get <группа>`,
  для точечного поиска — `... vk newsfeed.search <запрос>` (groups.search сервисному ключу недоступен).

ЗАДАЧИ
0. ПЕРВЫМ ДЕЛОМ разбери заявки из `suggestions.json`. Открой ссылку командой `read`, проверь
   старт по правилам для insert ниже. Итог по каждой заявке в `suggestions`:
   - подходит и его нет в календаре: status "added" и полный объект `insert` (как в разделе insert);
   - уже есть в календаре: status "duplicate", в note что именно;
   - не подходит (не Россия, прошёл, онлайн, детский, дату не подтвердить, ссылка мёртвая, спам): status "rejected", в note почему.
   Ссылка из заявки не считается подтверждением сама по себе: дату сверяй на странице организатора.
1. Сверь каждый старт из `manual.json`. Открой его страницы (source_url, reg_url, site_url)
   командой `npx tsx {{REPO}}/scripts/races-manual.ts read <url>`: это настоящий браузер,
   JS-страницы (RussiaRunning) читаются. Нужна дата самой гонки; у фестиваля день гонки,
   у многодневной гонки диапазон. Года на странице часто нет: сверяй по дню недели.
   - совпало: id в `checked`;
   - другая дата: запись в `update` с date_start, date_end, reason и source_url-подтверждением;
   - не открывается, отменён, не в России, дату не подтвердить: запись в `remove` с reason.
2. Обойди все сайты из `sources.json`. Каждый сайт с расписанием: новые старты в `insert`.
   По КАЖДОМУ обойдённому сайту запись в `sources` с last_checked = сегодня (по ней шлюз ставит
   следующий срок и считает, сколько новых стартов дал сайт) и status:
   ok (живой), dead (не открывается, пустой, зеркало другого календаря), blocked (robots.txt, капча, бан).
   robots.txt и блокировки не обходи: такой сайт сразу blocked с note.
3. Обойди точки из `cities.json`. По каждой 2-3 поисковых запроса («трейл <город> 2027»,
   «забег <город> <год>», «триатлон <город>», для мест вроде Шерегеша и Красной Поляны
   ещё «горный забег», «скайраннинг», «ультра»). ВК по точкам искать НЕ нужно: шлюз уже обошёл
   все точки, кандидаты в `vk-candidates.json` (см. выше). Каждый кандидат проверяй на сайте или
   в посте организатора. Шлюз отдаёт только посты открытых сообществ; людей и их данные не
   сохраняй — в insert только сам старт и ссылку на пост или группу (vk_url / source_url). Ищи особенно свои сайты организаторов (часто Тильда) со своей
   регистрацией: таких стартов нет ни в одном общем календаре (пример: Aurora Trail, Кандалакша).
   Все запросы в `queries`, запросы в ВК в `vk_queries`, обойдённые точки (имя как в cities.json)
   в `cities_searched`. Каждый новый сайт с расписанием сразу в `sources` с уровнем: tier "B", если у
   организатора или серии несколько стартов, tier "C", если старт один. Его старты в `insert`.
   Особое внимание триатлонам, дуатлонам, акватлонам, swimrun и горным забегам, в том числе на следующий год.
4. Перед каждым insert проверь дубль: `npx tsx {{REPO}}/scripts/races-manual.ts dup proposal.json`.
   Строки с пометкой ДУБЛЬ убери из `insert`.

ПРАВИЛА ДЛЯ insert
- Только Россия. Дата от сегодня до 31.12 следующего года.
- Дата подтверждена на сайте организатора, в его паблике или на его странице регистрации.
  Агрегатор (probeg.org, marathonec.ru и подобные) подтверждением не считается.
- Не добавлять: онлайн, абонементы, кемпы, тренировки, детские старты, заплывы без бега,
  стояние в воде, велогонки, OCR.
- Сайты, которые собирает робот (уровень A), НЕ обходить и в реестр не класть: probeg.org, marathonec.ru,
  iron-star.com, orgeo.ru, where2run.ru, myrace.info, sportsauce.ru, racetime.online, reg.place, reg.o-time.ru.
- Ничего не выдумывай. Не уверен в дате: не добавляй. Каждая ссылка должна быть открыта тобой.
- Без длинных тире в текстах, только дефис.

robots.txt), запиши его в `candidates`: url страницы со списком, примерное число стартов,
