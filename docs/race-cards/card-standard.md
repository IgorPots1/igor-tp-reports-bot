# Эталон гоночной карточки

Согласованный с Игорем формат. Отклоняться можно только по его прямой просьбе.

---

## 1. Структура карточки

Блоки идут строго в этом порядке. Лишние блоки не добавлять, пустые не оставлять.

| Блок | Класс | Что внутри |
|---|---|---|
| Шапка | `.hd` | надпись, имя, строка старта, дескрипторы трассы |
| Плита цели | `.goal` | цель или задача + короткое пояснение |
| Темп | `.sec` | ряды `.pace`, заметка, сверка по часам |
| Разминка | `.sec` | ряды `.step` |
| Питание и вода | `.sec` | ряды `.step` |
| Три главных | `.sec` | `ul.tips`, ровно три пункта |
| Подпись | `.cheer` | одна ободряющая строка |

На дистанциях от 21 км питание можно поднять выше разминки: там оно важнее.

### Шапка

```html
<div class="hd">
  <div class="eb">🏁 Гоночный план</div>      <!-- или «План на забег» -->
  <h1>Имя</h1>
  <div class="race">12 километров · Гребной канал, Ростов · на результат</div>
  <div class="tags">Плоская трасса · ровный темп от старта до финиша</div>
</div>
```

`.race` — дистанция, место, тип старта. `.tags` — 2–3 дескриптора трассы
через ` · `. **Плашек-чипов больше нет.** Их пробовали четыре раза, они
всегда вставали криво; Игорь велел заменить текстовой строкой. Не возвращать.

### Плита цели

Два режима, выбирается по тому, что ученик бежит:

```html
<!-- гонка на результат -->
<div class="lab">Цель</div><div class="t">50:30</div>
<div class="r">≈4:12 / км. При хорошем ходе <b>быстрее</b>.</div>

<!-- забег без борьбы за время -->
<div class="lab">Задача</div><div class="t">Пробежать</div>
<div class="r">Темп <b>6:30–6:50</b>. Ровно, спокойно, без борьбы за время.</div>
```

### Темп

Ряды `.pace`, последний ряд — `.pace.go` (зелёный, финишный).

```html
<div class="pace"><div class="pv">4:20</div><div class="rng">км 1–2</div>
  <div class="tx">Спокойно войдите в темп, <b>не разгоняйтесь</b>.</div></div>
<div class="pace go"><div class="pv">4:05↑</div><div class="rng">км 11–12</div>
  <div class="tx">Всё, что осталось. Финишируйте быстро.</div></div>
```

**Стрелка `↑`** означает «если всё хорошо, ускоряйтесь». Игорь просил именно
стрелку, без словесных пояснений в самой ячейке темпа.

### Сверка по часам

```html
<div class="subh">Сверка по часам</div>
<div class="chk">
  <div class="sp"><div class="d">3 км</div><div class="v">12:50</div></div>
  <div class="sp fin"><div class="d">финиш</div><div class="v">50:30</div></div>
</div>
```

Даётся **не до самого финиша**, а до точки, после которой ученик бежит по
самочувствию (обычно 70–80 % дистанции). Ниже обязательна заметка вида
«до N км держите ориентир, дальше по самочувствию». Финальная строка почти
всегда: «Быстрый финиш всегда лучше быстрого старта».

На рельефе сверку по каждому километру не давать: время будет колебаться.
Ориентир — среднее и самочувствие.

## 2. Тон и язык

### Обращение

Берётся из `trainingpeaks_students.telegram_formality`: `ty` / `vy`.
Если `unknown` — **спросить Игоря**, не угадывать.

### Запрещённые приёмы

| Нельзя | Надо |
|---|---|
| длинное тире ` — ` | запятая: `, ` |
| эффорт | усилие |
| улетать / не улетай | разгоняться / не разгоняйся |
| сплиты пляшут | время на километре будет колебаться |
| накат, добрать накатом | свободный бег, вернуть темп |
| бугры | подъёмы и спуски |
| разбудить ноги | подготовить ноги к быстрому бегу |
| разложись умно | пробеги грамотно |
| «уточняется», «примерно», «ориентировочно» о фактах | просто не писать этот факт |

Длинное тире вычищается автоматически на сборке:
`s.replace(" — ", ", ")`. Всё равно проверить глазами: в готовом
файле символа `—` быть не должно.

### Непроверенные факты

**Железное правило Игоря: чего не подтвердили, того в карточке нет.**

Это касается времени старта, города, названия забега, профиля трассы,
покрытия, количества кругов, погоды. Если источник один и сомнительный,
факт не идёт в карточку вообще. Формулировки «уточняется» и «ориентировочно»
запрещены: пустое место лучше неверного ориентира.

Разрешено писать только то, что: (а) сказал Игорь, (б) подтверждено
несколькими независимыми источниками, (в) видно на присланном им
регламенте или скриншоте.

## 3. Расчёт темпа

### Источник формы

Истинный рабочий темп — **`rep_paces`** из
`trainingpeaks_workout_derived_metrics` (массив сек/км по отрезкам).
Средний темп всей тренировки **не использовать**: он занижен разминкой,
трусцой между отрезками и заминкой. На этом уже ошибались.

Дополнительно смотреть:
- `source_snapshot->>'elevationGain'` — набор высоты. Результат с набором
  +55 м на десятке сильно лучше такого же по плоскому; цель поднимать.
- `avg_hr` и `heartRateAverage` — если на лёгком бегу пульс высокий,
  цель ставить консервативнее.
- Лучший результат на дистанции — отдельным запросом (см. `queries.sql`),
  сортировать по чистому темпу, а не по `velocityAverage`: последний
  считается по времени в движении и врёт.

### Ориентиры по дистанции

| Дистанция | Целевой темп относительно порога (`rep_paces`) |
|---|---|
| 5 км | быстрее порога на 5–10 с/км |
| 10 км | около порога |
| 12–15 км | порог + 0–5 с/км |
| 21,1 км | порог + 20–35 с/км |

Разложение всегда с **отрицательным сплитом**: первые 10–20 % дистанции
на 5–10 с/км медленнее рабочего темпа, финиш быстрее.

### Поправка на рельеф

Держать **усилие, а не темп**. В подъём шаг короче, темп отпустить:
ориентир 15–20 с/км на умеренном рельефе, 30–40 с/км на серьёзном.
На спуске вернуть свободным бегом. Мосты (Питер) — тот же приём,
10–15 с на въезде.

Итоговая цель на холмистой трассе ставится **заметно медленнее** плоской:
на 5 км это порядка минуты, не 10 секунд.

## 4. Питание и разминка

Устоявшиеся формулировки, менять только по просьбе Игоря.

### Питание

- **За 2–3 ч**: привычная еда с углеводами, нежирное. Ничего нового.
- **За 15 мин**: можно гель с кофеином, если привык. Пара глотков воды.
- **На дистанции 5–12 км**: гели не нужны, по желанию небольшой глоток
  воды на пункте.
- **На дистанции 21 км и выше**: питание каждые 30–40 минут начиная
  с 30-й минуты. Если ученик без гелей — мармелад или финики. Вода
  несколько глотков на каждом пункте.

Не писать: фрукты, солевые таблетки, изотоник, жилет и фляги —
если Игорь не сказал прямо.

### Разминка

- **10 мин** лёгкого бега с указанием конкретного темпа.
- **3–4 × 30 сек** ускорений в темпе около гоночного, между ними
  1 мин трусцой.
- Закончить **за 5–8 мин до старта**.

На дистанции 21 км и выше — только 10 минут лёгкого бега, ускорения не нужны.

## 5. Сборка и рендер

```bash
# 1. HTML пишется с плейсхолдером __STYLE__ вместо <style>
# 2. подстановка стиля + чистка тире
python3 - <<'PY'
css = open('pipeline/_style.css').read()
p = 'card.html'
s = open(p).read().replace('__STYLE__', css).replace(' — ', ', ')
open(p, 'w').write(s)
assert '—' not in s, 'остались длинные тире'
PY

# 3. рендер в PDF + PNG для проверки
node pipeline/gen.cjs ПАПКА_С_HTML
```

Расширение именно **`.cjs`**: в `package.json` репозитория стоит
`"type": "module"`, и файл с расширением `.js` Node попытается
загрузить как ESM и упадёт на `require`.

`puppeteer-core` в репозитории нет, ставится разово в отдельную папку:

```bash
mkdir -p ~/cards && cd ~/cards && npm init -y && npm i puppeteer-core
```

Браузер скачивать не нужно, Chromium уже есть в образе. `gen.cjs` находит
его сам перебором `/opt/pw-browsers/chromium*`; версия каталога меняется
от образа к образу, поэтому путь не захардкожен. Переопределяется
переменной `CHROME_PATH`.

`gen.cjs` рендерит страницу шириной **470 px** в PDF одной длинной
страницей (высота = высоте контента) и параллельно кладёт PNG.
**PNG обязательно посмотреть глазами перед отправкой**: так ловятся
переносы, разъезжающиеся колонки и обрезанный текст. Заодно скрипт
предупредит, если в файле остались длинные тире или неподставленный
`__STYLE__`.

Имена выходных файлов задаются в `cards.json` рядом с html:

```json
{ "valentin-card.html": "Валентин_12_километров" }
```

### Имена файлов

`Имя_Дистанция.pdf`, кириллицей, через подчёркивания:
`Валентин_12_километров.pdf`, `Ларионова_Северная_столица_21к.pdf`.

При отправке через SendUserFile кириллицу в JSON экранировать
последовательностями `\uXXXX`.

- [ ] Обращение совпадает с `telegram_formality`
- [ ] Символа `—` в файле нет
- [ ] Сленга из таблицы запретов нет
- [ ] Каждый факт о трассе подтверждён или отсутствует
- [ ] Темп посчитан от `rep_paces`, а не от среднего темпа сессии
- [ ] Цель учитывает рельеф
- [ ] Сверка обрывается до финиша, дальше по самочувствию
- [ ] Ровно три пункта в «Трёх главных»
- [ ] PNG просмотрен, вёрстка не поехала
