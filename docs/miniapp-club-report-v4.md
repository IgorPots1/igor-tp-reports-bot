## Блок 2+4 — рекорды из лучшего непрерывного отрезка + фильтр бег-усилия (главное)
Реализован локальный аналог strava best_efforts: скользящее окно по последовательным FIT-лапам находит самый быстрый непрерывный отрезок ≈ целевой дистанции. Паузы проверяются ВНУТРИ отрезка (порог 10% не менялся), темп по moving. Нет лапов/нерегулярная структура → падаем на старый метод «вся тренировка» (темп по elapsed), метод помечен `calcMethod`. Флаг `CLUB_RECORDS_BEST_SPLIT` (ВКЛ). Загрузка лапов/quality чанкуется (иначе `.in()` со всеми id переполнял URL и молча ронял всё на whole_workout — поймано на прогоне).

**Итог на реальных данных (`docs/records-best-split.md`): средняя дельта −146с** (новый метод точнее), 22 пары улучшено, **+124 рекорда**, которых старый метод не находил.
