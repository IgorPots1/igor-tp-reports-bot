# Шаблон кейса ученика для Instagram

Зафиксировано по итогам первого кейса (Марина Николаева, август 2026).
Следующие кейсы делаем по этому же образцу: `docs/cases/<фамилия>/`.

## 1. Формат

- **9 слайдов**, размер **1080×1350** (4:5), PNG.
- Нумерации слайдов НЕТ.
- **Длинных тире нет нигде**, ни на слайдах, ни в тексте поста. Только запятые,
  двоеточия, короткие дефисы в названиях.
- Порядок публикации задаётся именами файлов: `<имя>-01.png` … `<имя>-09.png`.

## 2. Скелет карусели

| Слайд | Что на нём | Обязательное |
|---|---|---|
| 1 | Обложка: фото во весь кадр, крупная цитата ученика, снизу главный результат «было → стало» | фраза самого ученика, не наша формулировка |
| 2 | Точка старта: 4 строки данных + короткая цитата из переписки | всё дословно и из протоколов |
| 3 | Хронология стартов таблицей, последний старт акцентом | только официальные протоколы |
| 4 | График главной дистанции | подписи словами, без жаргона |
| 5 | «Тот же пульс, другой бег»: плашки было/стало + график по временам года | пульс в обеих точках одинаковый |
| 6 | Вторая дистанция (полумарафон): фото во весь кадр + две плашки | |
| 7 | «За счёт чего»: дисциплина и физиология цифрами | выполнение плана, травмы, объём |
| 8 | Цитаты из переписки, 4 штуки, дуга «сомнения → перелом → результат» | реплики тренера подписывать явно |
| 9 | Финал: что входит в работу + «Нажимай ссылку в шапке профиля и вступай в наш клуб» | формулировки с лендинга |

## 3. Правила содержания

- **Цифры только из протоколов.** Темп считать от ОФИЦИАЛЬНОЙ дистанции, а не от
  дистанции по часам. Обе точки сравнения считать одинаково, иначе сравнение врёт.
- **Цитаты только дословные**, с датой из переписки. Пересказ своими словами
  выдаёт себя и убивает доверие.
- **Скрины переписки не вставляем**, оформляем цитатами в стиле карусели.
  Проверено на кейсе Марины: скрины Игорю не подошли.
- **Тезисы не обобщать.** «Каждый старт быстрее» верно только внутри одной
  дистанции, поэтому пишем «На каждой дистанции каждый старт быстрее».
- **Медицина в паблик не идёт** без отдельного явного согласия ученика.
- **Согласие ученика** на имя, цифры, цитаты и фото получаем до публикации.

## 4. Оформление

Тёмная «ночная» тема, одинаковая для всех кейсов:

```
--night   #0E1B2E   фон слайда
--night-2 #132539   плашки
--ink     #F3EFE6   основной текст
--muted   #93A3B8   подписи
--faint   #5C6E85   служебное
--dawn    #F2A45C   акцент (результат «стало»)
--s-was   #5E8FD1   серия «было» на графиках
--s-now   #CE7524   серия «стало» на графиках
```

Пара для графиков (`#5E8FD1` / `#CE7524`) проверена валидатором палитры:
проходит по контрасту и различима при дальтонизме. Не менять произвольно.

Фото-слайды: фотография во весь кадр, сверху и снизу градиенты для читаемости
текста. Внизу непрозрачность у самого края НЕ выше ~0.66, иначе кадр
превращается в тёмную заливку и выглядит как полоса.

## 5. Сборка картинок

Макет: один HTML-файл `instagram-carousel-mockup.html`, фотографии вшиты
как data URI (готовим кроп 1080×1350 через canvas).

Экспорт: `render.sh` + `pngcrop.py` (лежат в папке кейса Марины).

**Главная ловушка.** `chrome --headless --window-size=1080,1350` отрисовывает
только **1080×1263**, а скриншот пишет на полные 1350: нижние 87 пикселей
остаются пустым фоном страницы. На тёмных слайдах незаметно, на фото видно
полосой. Поэтому рендерим в окне **1080×1437** и обрезаем сверху до 1350.

Проверка готового файла: снизу не должно быть однотонной полосы.

## 6. Что собрать перед стартом кейса

1. Официальные результаты: `club_official_results` плюс скрины протоколов.
2. Динамика лёгкого бега по временам года: `trainingpeaks_workout_derived_metrics`
   (steady ≥20 мин, пульс 135–150), считаем средний темп и средний пульс.
3. Дисциплина: `trainingpeaks_workout_cache` (плановые против выполненных).
4. Физиология: пульс покоя и ВСР из `physio_readiness_daily`, объёмы из
   `club_week_rollup`.
5. Переписка: выгрузка Telegram в HTML, парсим в текст и вытаскиваем дугу цитат.
6. Фото от тренера: обложка (эмоция на финише) и второй старт.
