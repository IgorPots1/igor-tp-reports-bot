## Разделы (что делает каждый)
1. **Ревизия результатов** — таблица по ученикам с типом/доверием/причиной скрытия; ручной ввод гонки → `club_records` (source=coach_confirmed, trust=verified) перекрывает реконструкцию; «скрыть»/«сбросить»; массовый режим для ~110 человек.
2. **Очередь заявок** — старты/выходные/пожелания в одном списке, фильтры, подтверждение/отклонение (меняет статус в Supabase), пакетное подтверждение стартов. Исполнение в TP — Фаза 3, здесь НЕ делается.
3. **Telegram-привязки** — кто привязан/нет, ручная привязка/отвязка тренером (в мини-аппе ученика запрещена спекой), журнал попыток из `club_link_events`.
4. **Управление клубом** — режим цели челленджа (env CLUB_CHALLENGE_GOAL_MODE), свежесть/плотность/активные/покрытие пиков.
