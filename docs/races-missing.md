# Недостающие старты (окно 2026-10-11 ... 2027-12-31)

Всего найдено: **37** новых стартов, которых нет в race_calendar.json (405 записей).
Из них tri (триатлон, дуатлон, акватлон, зимний триатлон): **10**.

Сверка с базой: название (нормализация регистра, ё/е, кавычек, номеров), дата ±3 дня, город. Всё совпавшее исключено.

## Важные оговорки

- База уже очень плотная по probeg.org и orgeo.ru: почти все крупные трейлы и серии (Wild Trail, City Trail, RHR/goldenultra, Red Fox Elbrus, IRONSTAR, Triathlon X, O-Trail, Wild Siberia и др.) оказались дублями.
- 22 из 37 подтверждены на странице регистрации организатора в RussiaRunning (reg.russiarunning.com/event/...). Это страница, которую ведёт сам организатор, а не агрегатор, но у многих мелких стартов другого официального сайта нет. Страницы отрисовываются JS, поэтому данные (дата, место, дистанции, организатор) брались из публичного API той же страницы (/api/events/detailedEvent и /api/events/searchEvent, robots.txt reg.russiarunning.com разрешает всё).
- 11 записей: небольшие парковые забеги серии CITY RUN в Москве (Перовский сквер, Зеленоград). Детские и семейные «МУЛЬТИ СЕРИИ» (200 м - 2 км) исключены. Если такие мелкие старты не нужны, их легко отфильтровать по note «серия CITY RUN».
- 3 записи по Кировской области (Верхошижемье) взяты из официального календаря ФТР (rustriathlon.ru/api/calendar/list). Это спортивные соревнования ЕКП, а не массовые старты. Даты в календаре ФТР, похоже, включают день приезда.
- X-WATERS Урал и Руза: в основном это заплывы, в зачёт tri попали из-за акватлона в программе.
- Игры ЭкстримКрым (Крым): организатор перенёс фестиваль на 2027 год, даты 23-25.07.2027 есть только на странице регистрации.
- Исключены: онлайн-забеги, туры и кэмпы, детские лиги, «Пробежки с медалью» без номеров и хронометража, OCR (гонки с препятствиями), заплывы без беговой части, старты за пределами России.
