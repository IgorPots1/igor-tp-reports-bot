# Этап 3 — Отчёт: Mini App «Клуб» (`/m/club`)

Дата: 2026-07-24. Ветка `feature/miniapp-club`, worktree `/Users/igor/wt-miniapp-club`.

## Что сделано

Отдельная **ученическая** поверхность `/m/club` внутри Coach OS, изолированная от админского `/m/desk` и ученического `/m/n` (по твоей поправке): свой роут, неймспейс API `/api/m/club/*`, сервис-слой `src/features/club/*`, свой гейт и резолвер ученика. Общий базовый `/m/layout.tsx` не тронут (Oswald подключён локальным `src/app/m/club/layout.tsx`).

Всё **read-only** поверх `trainingpeaks_workout_cache` (+ `_laps`): в TrainingPeaks ничего не пишем и не инициируем, ученикам ничего не уходит (ни сообщений, ни уведомлений) — только UI. Всё за фичефлагом `CLUB_ENABLED` (+ внешний `MINIAPP_ENABLED`).

### Вкладки (v1)
- **Лента** — завершённые тренировки клуба: монограмма+имя, тип, дистанция, время, темп, дата, короткая подпись. Пагинация («показать ещё», курсор). Место под реакции заложено (задизейблено).
- **Челлендж** — клубный км к цели (прогресс-бар), «красавчики недели» по **проценту выполнения** тренировок (не по скорости/км), личный вклад ученика.
- **Рекорды** — реконструкция личных PR из кэша: полоса дистанции ±500 м + проверка стабильности темпа по `laps.pace_sec_per_km` (CV ≤ 0.08 либо узкая полоса ±150 м → «надёжный», иначе «предварительно»). 5k всегда «предварительно». Рядом — клубные топы по каждой дистанции.
- **Профиль / личный кабинет** — объём за неделю/месяц, серия дней, личные рекорды, место в челлендже.

## Поведение до/после
- **До:** мини-аппов два — `/m/desk` (тренер) и `/m/n` (питание). Клубной ленты/рекордов/челленджа нет.
- **После:** при включённых `MINIAPP_ENABLED=true` и `CLUB_ENABLED=true` появляется `/m/club` для учеников. При выключенном флаге все роуты возвращают 503 — выкатывается вслепую.

## На фикстурах / отложено
- **Цель клубного челленджа (км)** — фикстура (`CLUB_CHALLENGE_GOAL_KM_FIXTURE=500`): в Coach OS нет таблицы целей. Прогресс (клубный км) — реальный; цель в UI помечена «Демо-цель». → нужен реальный источник (мини-таблица `club_challenges` или env). См. `docs/questions.md §4`.
- **Аватары** — в схеме `trainingpeaks_students` нет; используется монограмма из имени.
- **Реакции/лайки** — только место в UI; данных/записи нет (по наряду).
- **Флаг приватности `club_visible`** — спроектирован (миграция-файл + фильтр-хук в сервисе), но НЕ применён в проде: до применения все активные несервисные ученики видимы по умолчанию (корректный дефолт «участвует»). Опт-аут активируется после применения миграции + добавления колонки в `select` (помечено в `service.ts: loadClubStudents`).
- **Надёжность рекордов** зависит от заполненности `trainingpeaks_workout_laps`. Где laps нет — рекорд честно помечается «предварительно» (цифры не подделываются).
