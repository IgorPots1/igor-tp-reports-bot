## 3.1 Тренер как участник
**Разведка `is_service_account` (флаг НЕ снимаем — он несущий):**
- `feedback-enqueue.ts` — исключает сервисные аккаунты из генерации фидбека.
- `tp-feedback-safety-net.ts` — то же для safety-net.
- `club-admin/repository.ts` — прячет сервисные из админских списков/статистики.
- `feedback/feedback-enqueue`, `measure-recency-and-fullread`, `check-club-*-parity`,
  `club-autobind-dryrun`, `measure-club-tabs` — везде фильтр `is_service_account !== true`.
- `trainingpeaks/repository.ts` — определение поля (миграция 20260721170000).
Снять флаг = начать генерить фидбек тренеру, тянуть его в биллинг/сигналы/дайджесты. **Не трогаем.**

**Решение:** клубный override, не снятие флага.
- `CLUB_INCLUDE_SERVICE_STUDENT_IDS` (список student_id) — в `isVisible` сервисный аккаунт виден в
  клубе только если он в этом списке. Больше нигде не читается.
- `CLUB_COACH_PARTICIPANT_STUDENT_ID` — маппинг coach_account → участник: тренерский Telegram
  (id в `TELEGRAM_COACH_CHAT_IDS`) при заданном env резолвится прямо в эту строку ученика
  (без автопривязки/подтверждения). Гард 403 для ВСЕХ остальных не тронут. Это снимает 403,
  оставаясь тренером в админке и участником в клубе.
- **Тренировки в агрегатах:** лента/профиль/публичный профиль читают сырой кэш → тренер появляется
  сразу, как только его student_id в include-set. Топы/челлендж/статистика под `CLUB_AGGREGATES_ENABLED`
  читают предвычисленные таблицы → тренер там появится ПОСЛЕ `materialize --all`, который тоже должен
  учесть include-set. **Открытый пункт → questions.md**: сейчас include-set читает только `isVisible`
  сервис-слоя; чтобы тренер попал в агрегатные топы, нужно, чтобы materialize/parity тоже
  включали его (правка скрипта materialize — отдельным пунктом, не в этой фазе, чтобы не задеть паритет).

## 3.8 Детальный экран тренировки (новый)
`POST /api/m/club/workout` → `getClubWorkoutDetail(workoutId)`:
- сетка метрик (дистанция, время, темп, ср./макс. пульс, каденс, набор — только при наличии);
- разбивка по лапам (№ · км · время · темп · пульс);
- мини-графики по лапам (темп/пульс/каденс);
- зоны пульса при `time_in_zones` (+ basis-подпись).
Читает лапы ОДНОЙ тренировки (`trainingpeaks_workout_laps` по `workout_cache_id`), не окно.
**Авторизация:** владелец виден в клубе ИЛИ это своя тренировка, иначе 404 (нельзя подсмотреть
скрытого по угаданному id).
