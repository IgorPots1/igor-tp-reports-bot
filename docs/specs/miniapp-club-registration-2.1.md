# ЭКРАН ПОДТВЕРЖДЕНИЯ ПРИВЯЗКИ (/m/club, первый вход)

Показывается, когда telegram_user_id ещё не привязан к ученику.

Содержимое экрана:
- Заголовок: «Привязка аккаунта»
- Текст: «Похоже, это твой аккаунт в клубе.»
- Имя ученика крупно: {Имя Фамилия}
- Пояснение: «После подтверждения этот Telegram будет привязан к твоему профилю. Изменить привязку можно только через тренера.»
- Кнопка (основная): «Да, это я»
- Кнопка (вторичная, текстовая): «Это не я»

ЗАПРЕЩЕНО показывать на этом экране: дату рождения, аватар, телефон, email,
любые тренировочные данные, вес, показатели, историю, суммы оплат.
Только имя. Экран видит непроверенный аккаунт.

## ПОТОК
- «Да, это я» → confirm-link → запись telegram_user_id → сразу лента клуба.
  Экран больше не показывается никогда.
- «Это не я» → доступ НЕ выдаётся. Экран: «Хорошо, ничего не привязали.
  Напиши тренеру, чтобы он проверил.» Кнопки повторить нет.
  Событие логируется (тип: rejected).
- Привязка однократная. Попытка привязать Telegram, уже связанный с другим
  учеником, или второй Telegram к тому же ученику → доступ не выдаётся,
  экран «Не получилось привязать, напиши тренеру», событие логируется
  (тип: conflict, с указанием обеих сторон конфликта).
- Отвязка и перепривязка из мини-аппа НЕВОЗМОЖНЫ. Только тренерская операция.

## ЛОГИРОВАНИЕ
Каждая попытка (confirmed | rejected | conflict) — кто, когда, результат, причина.
Отказы и конфликты должны быть видны тренеру в админке.

## Реализация (2026-07-25)

- Экран: `src/app/m/club/page.tsx` (`ConfirmScreen`) — точный текст выше; показывает ТОЛЬКО имя.
- Peek без записи: `resolveClubStudent` (`src/features/club/miniapp-guard.ts`) → `needs_confirm` с полным именем.
- «Да, это я» → `POST /api/m/club/confirm-link` → бинд через общий `resolveMiniAppStudent` (однократный, атомарный) → лента. При коллизии → терминальный экран «Не получилось привязать».
- «Это не я» → `POST /api/m/club/reject-link` → терминальный экран, без повтора.
- Логирование: `logClubLinkEvent` → таблица `club_link_events` (миграция `20260725140000`, НЕ применена; до применения — инертно). Конфликты дополнительно уходят тренеру в Telegram существующим резолвером.
- Отвязка/перепривязка из мини-аппа отсутствует (только тренерский SQL — см. `docs/miniapp-club-registration.md`).
- Админ-вью логов — следующий шаг (таблица-данные готова).
