Оплата и Прогноз вынесены в блок **«Кабинет»**. ЛОГИКА НЕ МЕНЯЛАСЬ — те же оверлеи, роуты, заявки,
инбокс, подтверждения; это перегруппировка входов. «Выходные» свёрнуты в «Расписание» (календарь и
так ставит day_off), отдельной кнопки «Выходные» больше нет; сам dayoff-оверлей остался в коде
(не открывается) — при желании удалю отдельно. Изменений логики потоков нет.

## Дотяжка гонок (продолжение F) — реализовано, запись за кнопкой тренера
`getClubRaceFillPlan()` + `applyRaceFillRecovery()` в репозитории. Админка **/admin/club/race-fill**:
кнопка «Восстановить N» (пишет coach_confirmed, по одной на ученика+дистанцию, самое быстрое время;
идемпотентно — существующие тренерские записи не трогает; откат в «Ревизии результатов») + список 21
недостижимой с ПРЕДЗАПОЛНЕННОЙ формой ручного ввода (ученик/дата/название есть; выбрать дистанцию + время).

**Факт по проду (dry-run плана):** восстановимо **29** записей (30 событий → 29 уникальных
ученик+дистанция), у **28** учеников появляется гонка; покрытие **5k=2, 10k=20, 21k=4, 42k=3**
(совпадает с «было» — теперь станут реальными записями вместо скрытых реконструкцией). Недостижимо
**21**: 8 без завершённого бега в день + 13 нестандартная дистанция — они в списке ручного ввода.

**ВАЖНО:** запись в прод (`club_records`) автономно НЕ делал — прод-мутация, видимая ученикам. Она за
кнопкой «Восстановить»: жмёт Игорь. Идемпотентно и обратимо (Ревизия результатов → Скрыть/Сбросить).

## ПРОВЕРКА ПОСЛЕ ВКЛЮЧЕНИЯ (что включить и на что смотреть)
Предпосылка: ветка влита, миграции 20260807/20260808 применены (включая колонку
club_prediction_visible), база клуба живая (MINIAPP_ENABLED, CLUB_ENABLED, CLUB_ADMIN_ENABLED = on).

1. **Иконки/разделы** — флага НЕ требуют, видны сразу после деплоя. Смотри: таб-бар (иконки, не эмодзи),
   Профиль → три карточки «Мои разделы» + «Кабинет», вкладка Клуб (свёрнутые топы, плитки статистики).
2. **Комментарии:** `CLUB_COMMENTS_ENABLED=true` → redeploy. Открой тренировку в ленте → секция
   «Комментарии»: добавить/изменить/удалить своё; `/admin/club/comments` — лента + удаление. Ученикам
   ничего не уходит.
3. **Прогноз:** `CLUB_PREDICTION_ENABLED=true` → Профиль → Кабинет → «Прогноз старта». Виден только при
   объявленном предстоящем старте и наличии гонок. Тумблер per-ученик — `/admin/club/prediction`.
   (Дотяжку гонок сделай ДО — тогда у 28 учеников появится якорь прогноза.)
4. **Оплата:** задай `CLUB_TBANK_PAYMENT_URL` (с `{label}`), затем `CLUB_BILLING_ENABLED=true`. Профиль →
   Кабинет → «Оплата»: статус/сумма/история, «Оплатить» (openLink), «Я оплатил» → `/admin/club/billing`.
   Напоминания: `CLUB_BILLING_REMINDERS_ENABLED=true` (там же должники + черновики).
   `CLUB_BILLING_REMINDER_AUTOSEND_ENABLED` держать OFF.
5. **Дотяжка гонок** (данные, не флаг): `/admin/club/race-fill` → «Восстановить 29». Затем в топах и
   `/admin/club/results` у 28 учеников появятся гонки (entered_by coach). 21 недостижимую — вручную там же.

Смотреть ПЕРВЫМ: (а) таб-бар без эмодзи + три карточки разделов; (б) комментарий проходит и виден в
админке; (в) после «Восстановить» — рост гонок в топах/Ревизии; (г) прогноз появляется только при
объявленном старте. Любой флаг обратно в false мгновенно гасит фичу, данные целы.
