## Расписание / рост ущерба
`backfill-coach-memory-v1` — ручной прогон (не в cron; запускается оператором для бэкфилла). Ущерб растёт не сам по себе, а на каждом РУЧНОМ прогоне бэкфилла для набора учеников, чья суммарная память > 1000. Сейчас 848 всего → порог не достигается. Диапазон дат «дублей»: 2026-05-31 … 2026-07-26 (совпадает с историей прогонов, не с автоматикой).
