## Метод (факт, не на глаз)
- **Имя** — тот же модуль, что для probeg: `enrichedSets` (варианты токенов: оригинал + транслит,
  мягкий знак, ё→е, любой порядок ФИО, script-agnostic) → `nameGate` (строгий tier: фамилия ТОЧНО +
  имя как префикс; мягкий tier: fuzzy/prefix). Кандидатные строки профиля: `name`, `first+last`, `nickname`.
- **Проверочный признак (обязательный)** — совпадение тренировок по **дате + дистанции**: Run Club тянет
  из Strava, мы из TP; один человек = одни и те же пробежки. Дистанция сравнивается в км
  (`normalizeKm(completed_distance_raw)` из метров ↔ `distance_km`), допуск `max(0.3 км, 8%)`.
- **Транспорт отфильтрован ДО сверки**: 20 пробежек с темпом < 2:30/км (поезд/машина как «бег»,
  README §5.1) выброшены, чтобы не давали ложных совпадений.

## Замечания
- Наших учеников в `trainingpeaks_students` — 125 строк (не 113): включает сервис/тест-аккаунты;
  на матч это не влияет (лишние просто ни с кем не совпадают).
- «Совпало тренировок» — это НЕ все пробежки, а пересечение по (дата, дистанция) с нашим кэшем TP;
  у активных пар оно десятки-сотни, что и подтверждает личность.
- Транспорт (темп < 2:30/км) выброшен до сверки — ни одно «рекордное» совпадение не участвует.
