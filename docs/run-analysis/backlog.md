## 1. Живой прогон на реальном видео (немедленно)

Проверить на одном-двух реальных видео сбоку:
- Скелет отображается корректно, hero frame информативный.
- Метрики разумны (каденс, углы — в ожидаемых диапазонах).
- Текст LLM звучит как Игорь, конкретный, без выдуманных данных.
- Нет незамеченных UX-проблем (зависание, медленная загрузка WASM и т.д.).

Если что-то не так — файлить в backlog или фиксить.

---

## 2. А/Б: Opus vs Sonnet на одном видео

Прогнать одно видео с `claude-opus-4-8` и `claude-sonnet-4-6` (через `RUN_ANALYSIS_CLAUDE_MODEL`). Сравнить качество нарратива и время ответа. Выбрать дефолт для прода и зафиксировать в [decisions.md](decisions.md).

## 4. PDF-экспорт (Фаза 2)

**Брендовый XO Runners PDF** — основной продукт для отдачи клиенту в Telegram.

- Собираем клиентски в браузере (canvas → jsPDF или html2canvas → blob → скачать).
- Hero frame уже есть как `heroFrameDataUrl` в `RunAnalysisResult`.
- XO Runners бренд (zinc-950 фон, yellow-400 акцент, Oswald/Manrope) — только в PDF, не на admin-странице.
- Кнопка «Скачать PDF» появляется в ReportView после завершения анализа.

**Начать отдельным диффом** — только после подтверждения качества экранного отчёта на реальных видео.

## 5. Instagram-бот с требованиями к видео

Рассылает потенциальным лидам инструкцию по съёмке видео.

Вне этого репо (ManyChat / ChatPlace / отдельный бот). Техническое требование к видео: MP4/MOV, строго сбоку, 5–10 секунд, 720p+, бегун полностью в кадре.
