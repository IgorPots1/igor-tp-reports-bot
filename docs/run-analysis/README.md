# Run Analysis — Анализатор техники бега

Административный инструмент в `/admin/coach-os/run-analysis`. Доступен только за admin-авторизацией; публичного роута нет.

## Как работает

**Слой замера (клиент, браузер):** Тренер загружает видео сбоку (MP4/MOV, ≤ 30 МБ). MediaPipe Pose Landmarker запускается прямо в браузере через WASM — никакой передачи видео на сервер. Из позных ориентиров (33 точки на кадр) вычисляются метрики: каденс, угол колена при опоре, наклон корпуса, вертикальная осцилляция, оверстрайд, тип приземления. Рядом live-обновляется canvas со скелетом — «вау»-момент, пока идёт обработка.

**LLM-слой (сервер):** На сервер уходит только JSON с профилем бегуна и посчитанными числами. LLM (дефолт `claude-opus-4-8`, переключается через env) пишет тренерский разбор голосом Игоря: ключевые находки с тяжестью (ok/attention/important), таблица метрик vs нормы, рекомендации с упражнениями, дисклеймер. Ответ — строгий JSON, разбирается defensive-парсером.

**Приватность имени ученика:** имя — клиентское поле, показывается только в шапке экранного отчёта. На сервер/LLM оно **не уходит** (в `runner_profile` серверного payload его нет) — никакого PII в запросах к модели.

## Бизнес-смысл

Ручной режим: Игорь сам грузит видео для конкретного ученика. Один и тот же инструмент — и для действующих клиентов (разбор в рамках коучинга), и для платного мини-магнита (лид делает видео, присылает, получает разбор за оплату). Доставка клиенту — вручную через Telegram. PDF-отчёт с брендом XO Runners — плановый следующий шаг после проверки экранного отчёта на реальных видео.
