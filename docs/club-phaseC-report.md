## Что сделано
- **Миграция 20260806**: расширил `club_challenges` — goal_type (km|workouts), goal_value, participant_scope
  (all|selected), participant_ids uuid[], status (active|completed|archived), created_by, completed_at;
  goal_km сделан nullable (для челленджа по числу тренировок). Обратная совместимость: manual-km путь и
  auto-цель не тронуты; goal_km бэкфилл из goal_value.
- **Создание мной (admin `/admin/club/challenges`)**: название, тип цели (километраж / число тренировок),
  период (даты), значение, участники (весь клуб / выбранные — student_id списком). Несколько активных сразу,
  история завершённых/архив, вернуть в активные. Ссылка добавлена на индексе `/admin/club`.
- **Прогресс**: `getClubActiveChallenges` считает клубный и личный прогресс по завершённым БЕГОВЫМ
  тренировкам участников в окне челленджа (км-сумма или число тренировок). Служебные пометки не учитываются
  (Фаза A исключает их в loadClubWorkoutRows). Толерантно к неприменённой миграции (возвращает []).
- **Мини-апп «Челлендж»**: показывает активные челленджи (каждый — прогресс клуба, мой вклад, доля, дней
  осталось); если активных нет — прежняя авто-цель клубного км. «Мой вклад · неделя» сохранён.
- **Красавчики: переключатель неделя / месяц** — pill-переключатель; месяц считается по календарному
  месяцу (сырой путь). API `/api/m/club/challenge` принимает `period`.
- **Авто-цель (среднее за 4 недели)** остаётся дефолтом, когда активных ручных челленджей нет — не тронута.
