## КЛЮЧЕВЫЕ УРОКИ ОТЛАДКИ (критично для будущих сессий)
1. **Фиксы Потока A работают в РЕНДЕРЕ, не переписывают stored `athlete_prose`.** Смотреть STORED в админке/БД = ложный «откат» (сырой текст модели с «adequacy», старым языком, «следующая неделя»). Проверять то, что видит ученица = **РЕНДЕР** (`/api/m/r` / combined-message), а не stored.
2. **«Выхолащивание» дня** (богатый сырой prose → терсные 4 строки «углеводов маловато…») = **валидатор `number_not_in_facts`** роняет день в детерминированный fallback, НЕ промпт/стиль. Конкретный баг: scrub чисел-длительности требовал пробел; «90-**минутного**» (дефис) не вычищался → «90» считалось выдуманным макро → reject → fallback. Бил по длительным/ключевым дням (там есть «90 мин»).
3. **Процесс:** когда Игорь говорит «чувствую, хуже» — копать на РЕАЛЬНЫХ текстах (сырой vs рендер, по дням), а не объяснять, почему всё ок. Первый аудит ошибочно закрыл реальный баг как «ложный/правило не режет» — повторное сравнение вскрыло валидатор. Не закрывать жалобу без проверки на данных.
