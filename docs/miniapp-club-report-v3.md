## Коммит 1 — приватность (`ddab239`)
- `loadClubStudents` читает `club_visible`. **Дефолт колонки в применённой миграции подтверждён из БД: `boolean NOT NULL default true`** (все участвуют).
- `isVisible` применяет опт-аут ТОЛЬКО при `CLUB_PRIVACY_ENABLED`; иначе флаг хранится, но игнорируется.
- Профиль отдаёт текущую видимость (`clubVisible`/`privacyEnabled`); переключатель в кабинете отражает состояние; свой кабинет виден даже при опт-ауте.
- Write-путь `/api/m/club/privacy`: авторизация по initData, пишет ТОЛЬКО свою строку (`.eq id`). Флаг ВЫКЛ.

## Коммит 2 — реакции (`51248b4`)
- `getClubFeed` агрегирует счётчики из `club_reactions` **одним запросом на страницу** (no N+1) + `mine`.
- `/api/m/club/react`: авторизация ТОЛЬКО по initData, `student_id` из резолвера (клиентский игнорируется); **идемпотентный тогл** по уникальному `(workout,student,kind)`; рейт-лимит 12/10с; `isWorkoutReactable` — нельзя реагировать на тренировку скрытого ученика.
- Ничего не шлётся и не уведомляется.
- RLS-миграция `20260725130000_club_reactions_rls.sql` (файл, НЕ применена): enable RLS + default-deny для anon/authenticated (service_role работает). Флаг ВЫКЛ.

- **Спеки v3 блок 2.1 в репозитории НЕТ** → реализована клуб-скоуп явная привязка: `resolveClubStudent` теперь только читает (peek), на непривязанном отдаёт `needs_confirm` с именем кандидата; экран «Это ты? {Имя}»; единственная точка бинда — `POST /api/m/club/confirm-link` после явного тапа (делегирует общему резолверу). `/m/n` не затронут.

## Что нужно от тебя, чтобы включить
1. Влить ветку + env `MINIAPP_ENABLED=true`, `CLUB_ENABLED=true`.
2. Приватность: `CLUB_PRIVACY_ENABLED=true` (миграция `club_visible` уже применена).
3. Реакции: `CLUB_REACTIONS_ENABLED=true` (таблица `club_reactions` применена; RLS-миграцию применить по желанию).
4. Цель: `CLUB_CHALLENGE_GOAL_MODE=auto` (дефолт) — среднее за 4 недели.
5. Регистрация теперь требует явного подтверждения в клубе (экран «Это ты?»). Если появится текст спеки v3 2.1 — подгоню формулировки.
