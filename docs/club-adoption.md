кому рассылка форм вообще дойдёт. Отправка идёт **от бота** (обычный `sendMessage`),
поэтому цель — `telegram_user_id` (личный чат с ботом), не business-DM `telegram_chat_id`.

## Реальные открытия КЛУБА — почти нулевые (ключевой вывод)

| Метрика | Значение |
|---|---|
| Открывали клубный мини-апп хотя бы раз (ПРОКСИ) | **~1** |
| Из них за последние 7 дней | 1 |
| Привязались сами через «Это я» (confirm-токен) | 0 |
| Одобрено заявок с general-link (тренер подтвердил) | 0 |
| Заявок висит неразобранными (`/admin/club/requests`) | **1** |

**Важно про прокси:** прямого лога открытий нет — `/api/m/club/clientlog` только пишет в
консоль, таблицы нет. «Открывали» считается как объединение клубных следов:
`club_link_events(result='confirmed')` ∪ `club_access_requests`. Оба почти пусты.

**Отсюда главный факт:** 106 `telegram_user_id` появились НЕ из клуба (в клубе нет
автопривязки — только confirm-токен или одобрение заявки, а их 0). Они пришли из бота /
nutrition-мини-аппа, где id уже был известен. То есть бот может достучаться до 106, но
**сам клуб они ещё не открывали**. Рассылка форм — это и есть первый заход учеников в клуб.

## Что это значит для рассылки

- Получатели формы: **106 привязанных**. Экран рассылки покажет их с чекбоксами и
  отдельным списком «нельзя отправить» (эти 6).
- Так как клуб почти никто не открывал, первая рассылка — это и активация: цель не только
  собрать формы, но и чтобы ученики впервые вошли в клуб.
- 1 заявка в `/admin/club/requests` ждёт разбора — стоит подтвердить до рассылки, тогда
  получателей станет 107.
