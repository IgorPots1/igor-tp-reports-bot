# Первый живой тренировочный цикл — как завести, проверить и откатить

Состояние на 2026-08-12. Документ написан ПЕРЕД заведением; сам цикл не заводился.

## Главное, что нужно знать до начала

**Вставить строку в `training_cycles` сегодня НЕДОСТАТОЧНО — её никто не прочитает.**

Проверено грепом по `tools/` и `src/`: единственное место, где таблица вообще упоминается, —
`tp-cycle-week-acceptance.ts`, и там она только СЧИТАЕТ активные строки для шапки отчёта.
Дальше скрипт всё равно строит цель недели через `buildDrafts()` — то есть из истории, а не
из того, что задал тренер. Читателя, который превращает строку таблицы в `CycleWeekTarget`,
в коде нет.

Поэтому порядок такой: сначала дописать читателя (отдельный наряд), потом заводить цикл.
Ниже — и то, и другое.

## Чего не хватает в коде и в таблице

| что | состояние | что делать |
|---|---|---|
| читатель `training_cycles` → `CycleWeekTarget` | **нет** | написать `loadActiveCycles(sb, weekStart)` рядом с `buildDrafts` |
| колонка `days` (сколько беговых дней) | **нет в таблице** | либо миграция `+ days integer`, либо брать из черновика по истории |
| колонка `start_week` (с какой недели идёт цикл) | **нет в таблице** | нужна: без неё `weekIndex` не посчитать, `forecast()` берёт `weekStart` параметром |
| `base_aerobic_min_manual` / `_quality_min_manual` / `_reason` | **есть, миграция применена** | проверено чтением колонок 12.08 |
| ручная база в коде | список `MANUAL_BASE` в `lib/cycle-drafts.ts` | после читателя перенести в колонки таблицы |
| `status = 'active'` | ничем не выставляется | выставлять руками при заведении |

Пока читателя нет, `MANUAL_BASE` в `cycle-drafts.ts` остаётся единственным способом задать
базу тренером. Механизм рабочий — проверено подменой: база 179 → неделя 185, база 140 →
неделя 145, база 220 → неделя 230, и состав недели меняется вместе с числом.

## Как завести

Только после того, как читатель написан и проверен.

```sql
-- ПЕРВЫЙ ЖИВОЙ ЦИКЛ. Числа взять из пакета приёмки на ту же неделю, не выдумывать.
insert into public.training_cycles (
  trainingpeaks_athlete_id, intent, target_date, status,
  length_weeks, base_aerobic_min, base_quality_min, notes, created_by
) values (
  5905779, 'half', '2026-09-12', 'active',
  5, 250, 25, 'первый живой цикл, заведён вручную', 'igor'
);
```

`base_aerobic_min` и `base_quality_min` — это БАЗА, а не цель первой недели: цель считает
`forecast()` шагом ×1.06 от базы. Сверить с пакетом: там у неё цель недели 275 = 250 + 25.

## Как проверить, что включилось

1. `select id, status, base_aerobic_min from training_cycles where status = 'active';` —
   строка одна, статус `active`.
2. Прогнать `npx tsx tools/trainingpeaks-export/scripts/tp-cycle-week-acceptance.ts` и
   посмотреть в шапке «АКТИВНЫХ ЦИКЛОВ В БАЗЕ СЕЙЧАС: 1» вместо 0.
3. В её неделе должна появиться заметка `цикл: неделя N из 5, роль «...»` — и число из
   таблицы, а не из истории. **Проверять именно это:** поставить в таблице базу, заведомо
   отличную от расчётной (например 300 вместо 250), и убедиться, что цель недели поехала.
   Если не поехала — читатель не подключён, а цикл берётся из черновика по истории.
4. `npm run check:cycle-forecast` — 26 из 26.
5. В TP ничего не должно появиться: цикл — это намерение, сессии пишутся отдельно и вручную.

## Как откатить

Отката кода не требуется — цикл влияет только через свою строку.

```sql
-- мягко: цикл перестаёт действовать, история остаётся
update public.training_cycles set status = 'cancelled', updated_at = now()
where trainingpeaks_athlete_id = 5905779 and status = 'active';
```

После этого атлет возвращается на прежний путь (конверт истории) — тот самый, по которому
сегодня идут все 112. Ничего доделывать не нужно.

Жёстко (если строка заведена ошибочно и мешает): `delete from public.training_cycles where id = '<id>';`

## Чего этот документ не покрывает

- Как заводить цикл из интерфейса — интерфейса нет, только SQL.
- Что делать, когда старт переносится: `target_date` меняется руками, пересчёт длины цикла
  автоматически не происходит.
- Поведение при двух активных циклах на одного атлета — не определено и не запрещено
  ограничением в таблице.
